# Phase 2B Curli Carrier Burden Scaffold

This directory contains template artifacts only.
No real cohort computation is executed in Phase 2B.
The burden estimate is a processed-table proxy and must later be validated
with targeted raw-read csg screening.

## Phase 1 marker reliability and interpretation

The Curli Carrier Burden score is a processed-table proxy and must not be interpreted as direct proof of curli gene presence, curli expression, or intact csg operon architecture.

Based on Phase 1 HMM validation, csgD, csgE, csgF, and csgG are treated as the most reliable curli-associated markers for downstream interpretation.

The csgA/csgB pair showed HMM cross-reactivity and should be interpreted cautiously, preferably as a combined csgAB structural/nucleator module rather than as perfectly separable gene-level evidence.

The csgC/csgE pair also showed partial cross-reactivity and should be interpreted cautiously in processed-table-level analyses.

Any Curli Carrier Burden signal obtained from processed abundance tables must later be validated by targeted raw-read csg screening before making gene-level or operon-level claims.
