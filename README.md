# Curli Carrier Burden analysis for Parkinson's disease gut microbiomes

This repository contains code and derived analysis scripts for a cohort-wise evaluation of Curli Carrier Burden (CCB), a trait-level microbiome index summarizing curated curli-carrier bacterial taxa in Parkinson's disease gut microbiome datasets.

## Main contents

- `scripts/`: analysis scripts for cohort screening, CCB calculation, and cohort-wise evidence synthesis.
- `tests/`: lightweight smoke tests.
- `metadata/`: curated curli-candidate taxa and small non-sensitive metadata tables.
- `manuscript/`: manuscript LaTeX source, figures, and tables, if included.
- `data/phase*/reports/`: small derived non-sensitive result summaries.

## Data availability

The repository does not redistribute controlled-access data, raw sequencing reads, or private participant-level metadata. Public processed resources and controlled-access resources should be obtained from their original repositories according to their terms of use.
