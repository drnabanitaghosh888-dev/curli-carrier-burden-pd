# PHASE2E Replication Processed-Table Verification Plan

## Why Replication Is Needed After Wallen
Phase 2D in Wallen identified a discovery-level processed-table signal that attenuated after adjustment. Replication is required to assess directional consistency, robustness, and uncertainty across independent cohorts.

## Scope
- Processed-table verification and provenance checks only.
- No FASTQ/SRA download.
- No raw-read processing.
- No gene-level or operon-level claims.

## Why Phase 3 Should Not Start Yet
Raw-read csg validation requires reliable run-accession mapping and clear access terms. This scaffold phase does not authorize raw-read execution.

## Expected Replication Evidence
- Shotgun metagenomic cohort suitability.
- Species abundance table availability.
- Sample metadata with linkable sample IDs.
- PD/control labels.
- Access/reuse terms.
- Optional: clinical/prodromal metadata for adjusted interpretation.

## Cohorts in Scope
- PALACIOS_PRODROMAL_PD
- NISHIWAKI_MULTICOUNTRY_PD
- MAO_CENTRAL_CHINA_PD
- INTEGRATED_US_MULTICOHORT_PD

16S-only cohorts are excluded from core replication analysis.
